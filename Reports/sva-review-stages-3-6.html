Требования промпта 6

Все пункты выполнены. Две оговорки: порог ухода в Worker задан числом циклов (SVA.syncLimit = 100 000 ≈ 200 мс), а не временем; «заметка о прогрессе» — статичная надпись. Оба в промпте 6.1.

Что ревью подтвердило как верное

  • Хэш-консинг потоков: одинаковый id остатка ⇒ одинаковое будущее; first_match-наборы сортируются и дедуплицируются; ошибок слияния не найдено.
  • Тайминг |-> / |=>, один консеквент на цикл конца антецедента, pass только когда антецедент больше не может совпасть; first_match в антецеденте; throughout проверяет условие на каждом цикле включая последний; intersect, within, [->n] / [=n].
  • $rose на цикле 0 из x, $past до начала = начальное значение типа, 2-state → 0; $stable / $changed точное сравнение; not вакуозного pass = fail; слабые операторы → active, сильные → fail в конце дампа; covers; правила ширины (a + b == 9'h100 держит перенос).
  • Страница: экранирование имён и текстов (файл с именем <img onerror> отрисовался текстом), ключи localStorage не пересекаются между страницами и видами, tv с z и многобитными x читается как описано в ENGINE.md, Worker даёт те же счётчики.

      Кандидаты на этапы 9+ (по спросу)

      • Локальные переменные в последовательностях ((a, v = data) ##1 b == v) — самая частая просьба в чекерах шин (TileLink tlul_assert, сопоставление ID в AXI). Требует уйти от чистого хэш-консинга: состояние потока = остаток + значения переменных.
      • Знаковая арифметика, $signed / $unsigned, знаковые порты — сейчас всё беззнаковое с предупреждением (после 5.1).
      • Асинхронный disable iff и @(posedge clk iff en) — нужны переходы, а не выборки, в ядре.
      • Generate-блоки и структуры конфигурации — откроют channel-файлы YosysHQ FVIP целиком; дорого, нужен элаборатор.
      • Сверка с симулятором: Verilator 5 с --assert пишет свои падения; прогон корпуса через него как внешний эталон.
      • Мультиклок — скорее нет: редкость в чекерах, большая цена в движке.
      • Производительность рисования больших результатов (1,2 МБ JSON на арбитре): хранить попытки компактно (typed arrays) после этапа 7, если страницы с десятками привязок на 16k циклов окажутся тяжёлыми.

Частично: итоги без результатов не показываются, «bound» считает непроверенные привязки (P4, P5); печатная таблица обрезается на A4 (P6); --update теряет ручные строки bind (T1); alias-привязка показывает нули (P3); замер сборки на арбитре воспроизвёлся (+1,15 с против заявленных +1,3 с).

Что ревью подтвердило как верное

  • Бары от X(cycles[start]) − pad до X(cycles[max(end, failed_at)]) + pad, кружки на X(cycles[c]) — 0 расхождений на масштабах 1 пс … fit, со сдвигами окна; попытки шире окна обрезаются, нулевой длины получают ширину 2·pad; слияние берёт самый сильный результат.
  • Clock-sampled вид: результаты сборки рисуются на своих фронтах, после Evaluate в странице — на тех же временах.
  • Выбор: клик по бару, f / F с переходом через край, кнопки отказов, Go to first failure, Esc; выбор в одном вьюере не трогает другой; фильтр по счётчику перестраивает полосу; привязки и результаты переживают перезагрузку.
  • Числа: страница = sva eval --report (md отличается только meta), sva report читает выгрузку страницы и даёт тот же md с выходом 1; печатный раздел = CLI (APB: 209 попыток, 47 pass, 2 fail).
  • Задержка: |=> = 1, |-> !b = 0, ##[0:3] b 1 / 1,33 / 2, s_eventually 2 / 2,33 / 3, слитые попытки 1 / 50,5 / 100; вакуозные, fail, active, capped исключены.
  • Экранирование враждебных имён (<img onerror>, |, `, &) в панели, SVG, статическом HTML, Markdown, JUnit; JUnit парсится ElementTree; today() совпал с календарём Python на 200 000 дней подряд.
  • Правило имён: точное имя бьёт префиксное, перекрывающиеся префиксы (длинный первым), иерархические имена, такт из области выше, выборка шире переменной не привязывается — одинаково в странице, svabuild.Names и sva eval --resolve scope.
  • Производительность ядра: арбитр eval + md + junit 0,08 с / 44 МБ; 17 000 отказов — все четыре формата 0,40 с.
